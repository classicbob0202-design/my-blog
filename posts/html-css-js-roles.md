클로드 코드와 함께 프레임워크 없이 이 블로그를 만들었습니다. 만들면서 웹 페이지를 이루는 세 가지 언어가 각각 무슨 일을 하는지 정리해 봅니다.

## 한 줄 요약

| 언어 | 역할 | 비유 |
| :--- | :--- | :--- |
| HTML | 내용과 구조 | 집의 뼈대 |
| CSS | 모양과 배치 | 인테리어 |
| JavaScript | 동작과 데이터 | 전기와 배관 |

## HTML: 내용과 구조

HTML은 페이지에 **무엇이 있는지** 알려 줍니다. 이 블로그에서는 `index.html`(글 목록)과 `post.html`(글 상세)이 HTML 파일입니다.

- `<header>`, `<main>`, `<article>`, `<footer>` 같은 **시맨틱 태그**를 쓰면 화면 읽기 프로그램과 검색 엔진이 구조를 이해하기 쉽습니다.
- `<meta name="viewport">` 한 줄이 있어야 모바일에서 화면이 제대로 맞춰집니다.
- 이미지에는 `alt`를 달아 그림을 볼 수 없는 사람에게도 내용을 전합니다.

## CSS: 모양과 배치

CSS는 내용을 **어떻게 보여 줄지** 정합니다. 블로그의 모든 스타일은 `css/style.css` 하나에 있습니다.

- 색상과 간격을 `--color-bg`, `--space-4` 같은 **CSS 변수**로 모아 두면 한곳만 고쳐도 전체가 바뀝니다.
- 다크 모드는 `[data-theme="dark"]`에서 색상 변수만 다시 정의해서 만들었습니다.
- **모바일 우선**으로 작은 화면 스타일을 먼저 쓰고, 넓은 화면은 `@media (min-width: 768px)`로 덧붙였습니다.
- 본문 폭을 `70ch` 정도로 제한하면 한 줄이 너무 길어지지 않아 읽기 편합니다.

## JavaScript: 동작과 데이터

JavaScript는 페이지가 **무엇을 할지** 정합니다. 이 블로그에서는 세 파일로 나눴습니다.

1. `markdown.js`: 마크다운 글을 HTML로 바꿉니다. 이때 본문을 먼저 이스케이프해서 `<script>` 같은 위험한 코드가 실행되지 않게 합니다.
2. `main.js`: `fetch()`로 글 목록과 마크다운 파일을 불러와 화면에 그립니다. 글을 찾지 못하면 안내 문구를 보여 줍니다.
3. `theme.js`: 다크 모드 버튼을 누르면 테마를 바꾸고 `localStorage`에 기억합니다.

```js
// 버튼을 누를 때마다 라이트와 다크를 번갈아 적용한다
button.addEventListener('click', () => {
  const next = currentTheme() === 'dark' ? 'light' : 'dark';
  applyTheme(next, button);
  storeTheme(next);
});
```

## 셋이 함께 일하는 순서

1. 브라우저가 **HTML**을 읽어 뼈대를 만듭니다.
2. **CSS**를 적용해 색과 배치를 입힙니다.
3. **JavaScript**가 마크다운 글을 불러와 HTML로 바꾸고 화면에 채웁니다.

> 역할을 나눠 두면 디자인을 바꿀 때는 CSS만, 기능을 바꿀 때는 JavaScript만 보면 됩니다.

## 배운 점

- 프레임워크 없이도 세 언어만으로 충분히 쓸 만한 블로그를 만들 수 있었습니다.
- `fetch()`는 `file://`로 열면 동작하지 않아서 `python -m http.server`로 로컬 서버를 띄워야 했습니다.
- 클로드 코드에게 `CLAUDE.md`로 규칙을 먼저 알려 주니 결과물이 일관되게 나왔습니다.
