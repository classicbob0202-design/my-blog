## 1. 규칙 파일은 '지금 상태'를 적어야 한다

claude.ai 채팅에서 만든 `CLAUDE.md`에는 앞으로 만들 폴더 구조가 이미 있는 것처럼 적혀 있었습니다. 그래서 **목표 구조**라고 표시하고, 실제 폴더를 먼저 확인하라는 문장을 넣었습니다.

## 2. 계획을 먼저 보고 승인한 뒤에 만든다

작업을 여섯 개로 나누고, 하나가 끝날 때마다 결과를 확인한 다음 넘어갔습니다. 한 번에 한 기능만 바꾸니 무엇이 왜 바뀌었는지 따라가기 쉬웠습니다.

## 3. 다크 모드는 CSS 변수와 인라인 스크립트로

- 색을 모두 변수로 두면 `html`의 `data-theme` 값만 바꿔도 전체 색이 바뀝니다.
- 테마를 정하는 짧은 스크립트를 `head` 안에 넣어 두면 페이지가 뜰 때 흰 화면이 번쩍이지 않습니다.

## 4. fetch를 쓰면 로컬 서버가 필요하다

글 데이터를 파일에서 불러오기 때문에, HTML 파일을 더블클릭해 열면 동작하지 않습니다. 아래처럼 서버를 띄우고 `localhost`로 열어야 합니다.

```bash
python -m http.server 8000
```

## 5. 화면에 데이터를 넣을 때는 textContent

`innerHTML` 대신 `textContent`를 쓰면 글 안에 HTML 태그가 섞여 있어도 글자 그대로 보여서 안전합니다. 주소의 `id` 값도 형식을 검사한 뒤에 사용했습니다.

## 6. 모바일 메뉴는 보이지 않는 부분도 챙긴다

- 버튼에 `aria-expanded`와 `aria-label`을 달아 스크린 리더가 메뉴 상태를 알 수 있게 했습니다.
- **Esc** 키로 메뉴가 닫힙니다.
- 버튼 바로 뒤에 메뉴를 두어 **Tab** 키 순서를 자연스럽게 맞췄습니다.

2. 라이트·다크 모드
3. 콘솔 에러
