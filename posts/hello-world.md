안녕하세요! 이 블로그는 **마크다운 파일**을 읽어서 웹 페이지로 보여줍니다.
프레임워크 없이 *HTML, CSS, JavaScript*만으로 만들었어요.

## 글 쓰는 방법

1. `posts/` 폴더에 새 마크다운 파일을 만듭니다.
2. 맨 위에 front matter를 적습니다.
   - `title`: 글 제목
   - `date`: 작성일 (`YYYY-MM-DD`)
   - `tags`: 태그 목록
3. `posts/index.json`에 파일 이름(slug)을 추가합니다.

> 좋은 글은 쉽게 읽히는 글입니다.
> 그래서 이 블로그는 장식보다 가독성을 먼저 생각했어요.

## 지원하는 문법

### 텍스트 꾸미기

**굵게**, *기울임*, ~~취소선~~, 그리고 `인라인 코드`를 쓸 수 있습니다.
링크는 [MDN 웹 문서](https://developer.mozilla.org/ko/)처럼 씁니다.

### 코드 블록

```js
function greet(name) {
  return `안녕하세요, ${name}님!`;
}

console.log(greet('독자'));
```
