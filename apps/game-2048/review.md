# 2048 게임 — 검증 결과 (review)

> 작성: Review 단계 / 2026-10-22
> 확인 환경: 내장 브라우저, `http://localhost:8000/apps/game-2048/`, 뷰포트 320·375·768·1280px 에뮬레이션, 라이트/다크 color-scheme 에뮬레이션

## 요약

**통과(작은 수정 1건).** spec 8장 체크리스트를 브라우저 콘솔과 실제 페이지에서 확인했고, 게임 규칙·흐름·저장·입력·레이아웃·대비 모두 spec과 일치한다. 결함은 하나 찾아서 고쳤다. 저장된 `over` 플래그가 판과 어긋나면, 막힌 판인데 오버레이가 뜨지 않아 진행이 멈추거나, 움직일 수 있는 판에 패배 오버레이가 떴다. 지금은 불러올 때 판 기준으로 `over`를 다시 계산한다. 콘솔 오류는 없고, 규칙 위반(`innerHTML`, `!important`, 절대 경로, 컴포넌트 색 리터럴, 전역 변수, 보호 없는 `localStorage`)도 없다. 나중에 추가된 두 규칙(블로그 색상 팔레트, 사용법 안내 문구)도 지킨다.

| 항목 | 판단 |

## 수정한 것

- **`main.js` `init()`** — 불러온 판의 `over`를 저장값 대신 `!canMove(saved.board)`로 계산한다.
  - 이유: 저장된 플래그가 판과 어긋나면(`over:false`인 막힌 판, `over:true`인 움직일 수 있는 판) 다음 문제가 생겼다. 막힌 판은 입력이 먹지 않는데 오버레이도 뜨지 않아 헤더 "새 게임"을 누르기 전까지 멈춰 있었다. 움직일 수 있는 판에는 패배 오버레이가 떴다. spec 2.3의 패배 정의(이동 불가)에 맞춘 것이고, 정상 저장값에서는 결과가 같다.
  - 다시 확인: 움직일 수 있는 판 + `over:true` → 오버레이 없음 / 막힌 판 + `over:false` → 패배 오버레이 / 정상 패배 판 → 패배 오버레이.
